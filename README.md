# 🔑 황금 열쇠 대탈출

거대한 아이의 놀이방에 갇힌 꼬마 장난감이 되어, 무지개 나선 계단 꼭대기의 황금 열쇠를 들고 쥐구멍으로 탈출하는 멀티플레이 3D 브라우저 게임입니다. (Three.js + Node.js WebSocket)

## 조작법
- `W A S D` / 방향키: 이동 (계단은 걷기만 해도 올라갑니다)
- `Space`: 점프 (짧게 누르면 낮게, 길게 누르면 높게)
- `Shift`: 대시 (2초마다, 공중에서도 가능)
- `E`: 아이템 쓰기
- 마우스 드래그: 둘러보기, 휠: 줌. 달리는 방향으로 카메라가 자동으로 따라옵니다 (설정에서 끌 수 있음)
- `1`~`4`: 이모티콘 (👋 😂 😱 👍), `Esc`: 설정
- 모바일: 화면 왼쪽 드래그로 이동, 오른쪽 드래그로 시점, 점프·대시·아이템 버튼

## 목표: 열쇠 조각 3개
황금 열쇠가 세 조각으로 흩어져 있습니다. 순서는 자유. 모두 모으면 쥐구멍이 열립니다.
- ⛰️ **꼭대기**: 나선 계단 끝의 황금 제단
- ☁️ **구름섬**: 계단 중간(26번째 칸)에서 움직이는 발판을 타고 방 한가운데 구름섬으로. 섬의 트램펄린은 제단까지 올려 줍니다
- 🧰 **보물상자**: 바닥의 빨간 버튼 두 개를 동시에 눌러야 열림. 블록을 밀어 올리거나 친구가 밟아도 됩니다

손에 잡히면 가장 최근에 얻은 조각 하나를 빼앗기고 체크포인트로 돌아갑니다.

## 게임 요소
- ❓ 아이템 상자: 🚀 부스터, 🦘 슈퍼 점프, 🛡 방패, 🍌 바나나 함정(친구가 밟으면 미끄러짐), ❄️ 얼음 폭탄(가까운 친구가 느려짐). 바나나와 얼음은 친구가 있을 때만 나옵니다
- ⭐ 별 14개: 모은 별은 누적되어 모자(고깔, 야구모자, 신사모, 고양이 귀, 프로펠러)를 엽니다
- 🚩 체크포인트 2곳, 🎪 트램펄린 지름길
- 🔴 구슬, 🌀 빙글빙글 막대: 맞으면 튕겨 나가니 점프로 피하기
- ✋ 손: 빨간 원이 보이면 피하세요. 높이 올라갈수록, 조각을 많이 들수록 더 자주 내려칩니다

## ⚔️ 열쇠 쟁탈전 (경쟁 모드)
설정(⚙️)의 **게임 방식**에서 바꾸면 방 전체가 쟁탈전으로 전환됩니다.
- 열쇠 조각이 방에 **한 세트뿐**입니다. 먼저 집은 사람이 가져갑니다
- 조각을 든 친구와 **부딪히면 하나를 빼앗습니다**. 빼앗은 직후 2초 동안은 다시 빼앗기지 않습니다
- 조각을 들면 조금 느려집니다. 손에 잡히면 조각 하나가 제자리로 돌아갑니다
- 세 조각을 모두 들고 쥐구멍에 들어가면 그 판 승리. **3판을 먼저 이기면 최종 우승**
- 누가 무엇을 들고 있는지는 서버가 판정합니다

## 함께 플레이
같은 주소로 접속하면 같은 방(lobby)에서 만납니다. 방을 나누려면 주소 뒤에 `?room=원하는코드`를 붙이세요. 방당 최대 24명.
- 🏁 **다 같이 출발**: 누르면 방 전체가 카운트다운 후 함께 출발합니다
- 🏆 방 기록: 탈출 기록 상위 10명이 방에 남고, 1등은 👑 왕관을 씁니다 (서버가 재시작되면 초기화)
- 탈출한 뒤에는 달리는 친구를 구경할 수 있어요

## 로컬 실행
```bash
npm install
npm start   # http://localhost:3000
```

## 구조
- `server.js`: 정적 파일(gzip) + WebSocket 중계, 방 기록, 동시 출발
- `public/index.html`, `public/style.css`: 화면 틀
- `public/game.js`: 게임 본체

## Render 배포
`render.yaml`이 포함되어 있어 Render에서 New → Blueprint로 이 저장소를 선택하면 됩니다. (Build: `npm install`, Start: `npm start`)
